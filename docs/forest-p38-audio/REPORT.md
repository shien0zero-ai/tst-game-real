# P38実録音と森林の余韻への差し替え（2026-11-18）

標準SERVICEの発砲を無料GameAudioGDC配布のPole Position P38録音へ変更。森のグラフィック、Cinematic、1920×1080、内部解像度100%、環境音・足音・M1911・旧音源と過去の配布版を保持。追加の購入・ソフト導入・エンジン編集なし。

## 採用した無料素材

P38の直接音とマガジン操作はGDC2020配布分、森林の余韻はGDC2018配布分です。[公式無料配布](https://sonniss.com/gameaudiogdc/)とそこからリンクされた収録一覧でファイル名を確認。製品版の全ライブラリを購入したものではありません。

- P38, Firing, t1, 2m, Behind, LS5.wav：後方2m、96kHz/24bit stereoの原録音から、右チャンネルの異なる実発砲3テイクを選択。射手の耳位置そのものの録音とは主張しません。[原作者のライブラリ説明](https://pole.se/product/walther-p38-semi-automatic-pistol/)
- MP5_forest_road_10m_behind_gun_pointing_at_forest_off_axis_MKH8060.wav：森林に向けた発砲を林道で録音した素材。発砲直後100msを除き、2種類の減衰だけを使用。MP5の破裂音をP38の直接音として使っていません。[屋外音響ライブラリ](https://sonniss.com/sound-effects/outdoor-gun-acoustics-library/)
- P38, Handling, Removing Magazine, 1m, Right, MKH8060.wav：標準拳銃のマガジン取り外しへ使用。旧操作音は保持。

FreesoundのP38森林録音も候補でしたが、確認できた試聴版を原音と同等に扱わず不採用。屋内録音、サプレッサー録音、合成SF音、クリッピングを特徴としている素材も選んでいません。

## 再生処理

旧PPQの代替近接音と中距離録音の重ね方を標準拳銃から外し、P38の短い直接音（0.20秒）と森林の減衰（2.2秒）へ分離。発砲直後はP38本来の作動を含む録音を使い、別銃の短い操作音を同時に重ねません。直接音は銃の位置から3D再生し、自分の発砲は自己遮蔽で不自然にこもらせません。余韻は世界座標に残り、距離と遮蔽で変化します。近距離では広がりを残し、離れると定位を付けます。

合成低音、ピッチ下げ、飽和、人工的な薬莢音、長い室内リバーブは追加していません。ゲーム内直接音ゲインは旧0.78から0.74で、単なる音量増加ではありません。48kHz PCM16へのアンチエイリアス変換、25HzのDC/超低域整理、短いフェード、レイヤー群で共通のゲインを使用。全6アセットはCook後もPCMです。音源本体は原作者の録音の範囲内で、商用FPS同等の聴感品質を数値だけで保証するものではありません。

F3のM1911は従来の実録.45音を維持。`-ForestPreviousGunfire`は従来の標準拳銃の音と比較する開発用起動フラグです。

## 実際のUE出力の検証

Editorビルド成功、実PIE 32 PASS、Windows版 32 PASS、いずれも0 FAIL。MSVC14.52.37029 / Windows SDK10.0.26100.0。既知の起動時AutomationTestログとコンパイラー警告は抑制していません。

UEのマスター出力を48000Hz・8ch・35.008秒録音。5距離/遮蔽場面に加え、森の環境音を戻して実際のFireを8回実行し、弾消費と重なりを確認。全録音のデジタルクリップは0サンプル。50mの遮蔽でRMSが9.80dB低下。これは録音した全チャンネルの値で、実際の音圧や聴感の自然さの評価ではありません。

最初の画面外録音は全サンプル無音で検査不合格。UE既定の非アクティブ時音量0が関係するため、明示的な音響QAプロセスだけ非アクティブ時の再生を有効にして再測定しました。変更前の診断ログ：`focus=0 volume=0.000 unfocused=0.000 / test process only`。この変更と無音時Submix停止の回避はQA起動だけで、通常ゲーム・OS・エンジン設定ファイルへは適用しません。失敗した初回JSONも保存しています。

原録音にはフルスケール近傍の短い値があり、選択チャンネルの3テイクには1/2/1サンプル。加工で元の情報を復元したとは主張しません。森林減衰の選択区間では該当値0。変換後アセットと最終ミックスでクリップ0を別々に確認しています。

## 保存・再現

[現在の利用条件](https://sonniss.com/gdc-bundle-license/)に従い、録音は完成ゲームに組み込みます。CC0ではないため原音・派生WAV・単独SoundWave・孤立した音声QA録音は公開Gitへ含めません。原音はローカルwork/p38-source-cacheへ保持し、旧CC0バンクはそのまま保存。出典・ローカルSHA256・加工条件・コードを公開Gitに保存し、初回Editorビルドで不足する無料音源を取得/検証して取り込みます。ダウンロード時のSHA256であり、配布元の原本照合済みという意味ではありません。詳しいクレジットはlicenses/forest/P38-FIELD.txt。

Tools/build_forest.ps1 -Action Editor → PIE → Windows → Verify。音響検証は配布版へ-ForestAcousticQA -ForestAudioBurstを指定し、Tools/analyze_acoustics.pyで出力WAVとログを検査。完成ZIPは新規フォルダーへ全展開し、従来の13入力項目に加えてP38バンクの実再生ログを確認してから公開します。

森林の生成関数と設定ファイルが前版ad32d2cから変わらないことを検査。FPSは今回再測定しておらず、前版の目標未達を改善済みとは扱いません。樹種や湿度を解く波動音響シミュレーションは実装していません。

初回ZIP検査は右クリックでaim=1にならず停止しました。クラッシュではなく、終了確認までゲームは動作していました。検査のRMBをPostMessageからOSの実マウスイベントへ変更し、クライアント中央へカーソルを合わせて再検査。照準・射撃・リロード・M1911・メニューを含む13状態すべてPASS。照準の判定を含む既存の合否条件は維持し、ゲームバイナリは変更していません。公開前には最新source commitを記録した最終ZIPを再展開し、同じ入力ゲートをもう一度実行します。
