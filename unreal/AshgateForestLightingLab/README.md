# ASHGATE / FOREST LIGHTING LAB

既存の森林デモを残して、64×64mの同一区画でLumenと事前計算した照明を比較するUE5.8.4 / C++試作です。地形の形状・植生の配置・テクスチャ・銃・手・音を元のデモから引き継ぎ、Cinematic、1920×1080、内部解像度100%を維持します。

## Windows版の起動

ZIPをすべて展開して、比較する起動ファイルを開いてください。

- `01-Baked.cmd`：小区画。地面のライトマップ＋ボリューメトリックライトマップ。銃・手は動的照明。SSRと森林の反射キャプチャを使用。
- `02-Patch-Lumen.cmd`：同じ小区画・配置でLumen GI／反射を使用。
- `03-Full-Lumen.cmd`：元の256m森林を同じコードと素材で再現。比較用の共通ルートを内蔵。

いずれも右上に実測FPSを表示します。WASDで移動、マウスで視点、左クリックで発砲、右クリックで照準、Rで装填、Fで銃の点検、F2で銃を隠す、F3で保存したM1911へ切り替え、Escでメニューです。小区画では地面の端から落ちないように移動範囲を制限します。遠景が途切れる区画試験であり、完成した全森林の代替ではありません。

## 照明方式と制限

CPU Lightmassで保存した照明を使用します。静止した地面には専用UVの表面ライトマップを、植生・動く銃・手には空間内の間接光を使用します。照明計算時は太陽とスカイライトをStationaryとし、実行時には太陽の直接光と影をMovableとして扱います。銃・手の動的な影と接触影、近くの木陰を残しています。

Nanite植生に対応するためVSMを維持しており、遠方の動的な影も残る構成です。太陽の直接光と遠景の影まで全面的に事前計算した方式とは区別してください。既存の植生UVには重複があり、これを表面ライトマップには使っていません。Lightmassの警告は保存し、抑制していません。起動直後の粗い影キャッシュを残さないよう、開始8秒間はキャッシュを更新し、その後は通常のキャッシュを有効に戻します。

照明・反射の計算法は変わるため、Lumenとの見た目の完全一致は保証しません。実測値と比較画像は[検証結果](VALIDATION.md)を参照してください。既存版そのものの測定と、同一区画の公平な照明比較を分けて記録しています。

## ソースから開く

追加ソフトのインストールは行いません。元デモのネイティブ素材を復元済みの環境で、`Tools/build_lab.ps1 -Action Editor`を実行し、`AshgateForestLightingLab.uproject`を開きます。素材は元プロジェクトから足りないファイルだけコピーし、既存ファイルを上書きしません。

保存済みマップ・地面メッシュ・照明データはバージョン管理します。大きな照明データはSourceArt/Packedに可逆圧縮して保存し、SHA-256付きで復元します。通常のEditor／Windowsビルドでは、再インポートや再計算を行いません。再作成する場合だけ、Editorビルド後に`-Action Prepare`、`-Action Bake`を順に実行してください。Prepareはこの試作用マップを作り直す操作です。Bakeは保存用ファイルの存在を検査し、PIE／Verifyが再起動後の読み込みを検査します。

`-Action PIE`で実PIE、`-Action Windows`で独立したWindowsパッケージ、`-Action Verify`で実行版を検証します。出力先は`work/forest-lighting-lab-package`で、元の`work/forest-package`を使用しません。`Tools/benchmark_lab.ps1 -Variant Lumen`または`Baked`で、同じ3ルートを前面表示しながら測定できます。測定中は別ウィンドウに切り替えないでください。前面表示の喪失は失敗として記録します。

## 保存と素材

元の`unreal/AshgateForest`、Godot版、Depot版、過去の配布物とセーブを保持します。新しい配布物は別名のLighting Lab ZIPです。元デモの素材クレジットと`licenses`を継承します。P38録音はGDCライセンスのゲーム組み込み素材で、音源やSoundWave単体の配布は行いません。
