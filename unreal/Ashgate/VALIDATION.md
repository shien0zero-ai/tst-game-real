# ローカル検証結果 — 2026-11-12

Windows本体、UE5 5.8.4、Ryzen 9 9950X3D、RTX 5080、約32GB RAM。エンジン・Godot版・素材原本の改造、追加インストール、既知の警告・テストの抑制は行っていません。

## ビルドとゲーム処理

| 項目 | 最終結果 |
|---|---|
| Win64 Development Editor | 成功 |
| Win64 DevelopmentのBuild/Cook/Stage/Archive | 成功、UAT終了コード0 |
| 実際のPIE | `worldtype=3`、29 PASS / 0 FAIL、Editor終了コード0 |
| 配布用EXE | `worldtype=1`、29 PASS / 0 FAIL、終了コード0 |
| GPU | D3D12の選択アダプターとRHI名がRTX 5080 |
| 材質 | 最終PIE・配布版・入力検証で材質コンパイル失敗、invalid ShaderMap、Fatal errorは0件 |

MSVCは14.52.37029（フォルダー14.52.37025）、Windows SDKは10.0.26100.0です。推奨より新しいMSVCの警告は残ります。初回Editorビルドでは既知のエンジンAttribute.h:195のC4864も出ています。

PIE起動時には既知の `Condition failed` 19行が残っています。最終配布版とその入力検証では該当行は0でした。エンジンテストの原因が解明・修正されたという意味ではありません。

29項目は実際に動くワールドで、移動、武器確認、ADS中断、単発の弾消費、リロード中断と完了、被弾による治療中断とキット消費、バッグのEsc処理、ケースの照準・回収・二重回収防止・満杯時の維持、銃声への反応、プレイヤーと敵の双方の射線遮蔽、敵の被弾・死亡・回収、出撃の事前引き落としとディスク保存、脱出カウントと範囲外リセット、装備・物資返却と報酬、売却、失敗時の携行品喪失、感度の保存を確認します。

これは実ゲームメソッドと時間経過を使う自動検証です。敵の戦闘バランス、すべての巡回経路、長時間プレイ、人間の操作感を評価し尽くしたものではありません。死亡時の装備喪失は失敗遷移として検証しており、10分の自然なタイムアウトやOS強制終了からの再開を実時間で試したものではありません。

## Windowsゲームの入力経路

配布用ゲームを起動し、対象ウィンドウへWindowsのキーイベントとマウスクリックを送りました。テスト用F9で状態と実画面を記録し、次の14時点をログで確認しました。通常プレイではF9検証機能は有効になりません。

| 入力 | 確認した状態 |
|---|---|
| 拠点の射撃場をマウスでクリック | base → raid |
| Wを1秒押す | X=-3900/Y=-3300 → X=-3638.261/Y=-3109.835、約3.24m移動 |
| N | inspect=3.94秒 |
| 右クリック | aiming=1、inspect=0 |
| 左クリック | ammo=7 → 6 |
| R / 待機 | reload=1.10 → 完了、ammo=7 |
| Tab | bag=1、paused=0 |
| Esc | bag=0、paused=0 |
| もう一度Esc | paused=1 |
| 感度+をクリック | sensitivity=1.00 → 1.10 |
| Esc | paused=0、感度1.10を維持 |
| ポーズから拠点へ戻る | phase=base |

ゲームは終了コード0で終了しました。検証はQA用スロットだけを使い、カーソル位置と元の前面ウィンドウを戻しました。人間による長時間の手動プレイは未実施です。

最終ワールド検証の12秒区間で、配布版の平均ゲームフレーム間隔は5.99ms（約166.9 FPS）、最大10.35ms。出力は1600×900、保存済み画質設定2（High）。PIEは1280×722、平均8.33ms（120 FPS）、最大8.94msでした。

上記の計測ではPIEと配布版を同時に起動しています。Windows専用設定を確定した後の配布版単独での再検証でも29 PASS / 0 FAIL、終了コード0を確認し、同じ固定視点・12秒では平均4.19ms（238.8 FPS）、最大6.19msでした。起動・シェーダー準備・スクリーンショットを除いた、射撃場の固定視点の短時間サンプルです。GPUタイムスタンプや全マップの1% lowではなく、ゲームTickのDeltaSecondsによる計測で、内部のアップスケール解像度は別途記録していません。戦闘中・他PCでの性能保証には使えません。

画面で材質・銃・HUDが表示されることを確認しました。画作りはまだブロックアウトに既存PBR素材と小物を加えた初期段階です。屋内照明、環境密度、壁面データマップの投影、手と警備員のポーズ・銃の持ち方、NavMesh経路探索は残作業です。Bodycam相当のフォトリアル品質は未達です。

## 証跡の場所

ローカルの詳細ログは `unreal/Ashgate/Saved/` のEditorBuild.log、ArtImport.log、PackageBuild-console.txt、PIE-QA.log、PackagedQA.log、PackagedInput.logです。生ログ・QAセーブ・中間生成物はGitや配布ZIPには含めず、検証抜粋と選んだ実画面だけをソース管理します。

配布フォルダー直下のAshgate.exe（起動口）からの子ゲーム起動も別途確認し、READY、RTX 5080選択、quitによる終了ログを確認しました。

配布ZIP内のVC++ランタイムは Engine/Extras/Redist/en-us/vc_redist.x64.exe です。改訂版r1はこの案内を訂正した文書更新で、検証済みゲームバイナリは同一です。
